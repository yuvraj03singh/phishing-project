# Hybrid Ensemble Architectures

## Approach A: Weighted Soft Voting Ensemble

The soft-voting classifier aggregates class posterior probabilities generated by $K$ strong diverse base estimators:

$$P_{voting}(y = 1 \mid \mathbf{x}) = \frac{\sum_{i=1}^K w_i \cdot P_i(y = 1 \mid \mathbf{x})}{\sum_{i=1}^K w_i}$$

Where base estimators comprise:
1. **XGBoost Classifier** ($w_1 = 0.25$)
2. **Random Forest Classifier** ($w_2 = 0.20$)
3. **Extra Trees Classifier** ($w_3 = 0.20$)
4. **LightGBM Classifier** ($w_4 = 0.20$)
5. **Gradient Boosting Classifier** ($w_5 = 0.15$)

## Approach B: 2-Tier Stacking with Out-of-Fold Meta-Learning

To maximize generalization without data leakage:
1. **Level 0 (Base Learners):**
   A 5-fold stratified partition generates out-of-fold probability vectors $\mathbf{z}_i \in \mathbb{R}^K$ for each training instance.
2. **Level 1 (Meta-Learner):**
   A Logistic Regression classifier with L2 penalty ($C=1.0$) is trained on the meta-feature matrix $\mathbf{Z} \in \mathbb{R}^{N \times K}$:

$$\hat{y}_{stack} = \sigma\left( \mathbf{w}^T \mathbf{z}(\mathbf{x}) + b \right)$$

This two-tier structure balances the high expressive power of gradient boosting with the regularized calibration of linear meta-learners.
